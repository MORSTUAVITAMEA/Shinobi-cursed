SHINOBI × CURSED: PIXEL CLASH
Fan game gratuito non ufficiale, pensato per smartphone. Non include contenuti presi da giochi o anime.

CONTENUTO
index.html = gioco
manifest.webmanifest + sw.js = installazione come web app e funzionamento offline (dopo il primo accesso)
icon-192.png / icon-512.png = icone

COME PUBBLICARLO GRATIS SU GITHUB PAGES
1. Crea un repository pubblico su github.com (per esempio 'Pixel-Clash').
2. Carica TUTTI i file di questa cartella nella radice del repository.
3. Apri Settings > Pages > Build and deployment.
4. Seleziona Deploy from a branch, branch main, folder / (root), poi Save.
5. Il link sarà del tipo https://TUO-UTENTE.github.io/Pixel-Clash/ (può richiedere qualche minuto per attivarsi).

SU IPHONE
Apri il link con Safari, tocca Condividi e poi Aggiungi alla schermata Home.
Dopo il primo caricamento completo, il gioco può funzionare anche offline.
Gira il telefono in orizzontale per un'esperienza più comoda.

CONTROLLI TOUCH
Frecce = movimento, ↑ = salto, Pugno = attacco, Tecnica = abilità speciale, Para = difesa, Finale = attacco supremo (energia al 100%).
Su PC: A/D o frecce = muoviti, W/↑ = salta, J/spazio = colpo, K = tecnica, L = finale, Shift = parata, Esc = pausa.

NOTA: questa è una PWA installabile dalla schermata Home, NON un file IPA per AltStore.
